# 管理员使用指南

## 1. 登录管理后台

访问站点根路径 `/`，输入部署时设置的 `ACCESS_PASSWORD`。管理员会话使用 HttpOnly Cookie、同源校验和 CSRF 防护。

## 2. 导入邮箱

在“邮箱果园”中选择“导入账号”。支持：

- JSONL，每行一个对象：`email`、`password`、`clientId`、`refreshToken`。
- 文本格式：`邮箱----密码----Client ID----Refresh Token`。

邮箱密码与 Microsoft refresh token 使用 Fernet 加密后保存。请勿通过聊天记录或公开渠道传递导入文件。

## 3. 管理可出租状态

账号列表的“出租状态”包含：

- **可出租**：可以被自动分配或指定创建租约。
- **租用中**：存在尚未结束的租约。
- **已停用**：管理员关闭了该邮箱的后续出租。

停止出租不会自动结束已有租约。如需立即回收，请同时撤销租约。

## 4. 创建租约

点击“创建租约”，可以留空账号 ID 让系统自动选择可用邮箱，也可以填写账号 ID 指定邮箱。

### 指定到期时间

选择“指定到期时间”，填写本地日期和时间。浏览器提交时会转换为 UTC。后端要求：

- 时间必须包含时区；
- 到期时间至少晚于当前时间 `RENTAL_MIN_MINUTES`；
- 到期时间不能超过 `RENTAL_MAX_MINUTES` 允许的范围。

租约到期后，系统在下一次租约查询或分配时将其标记结束，邮箱重新进入可分配池。

### 永不过期

选择“永不过期”后，租约不会自动结束，邮箱会一直被该租约占用，直到管理员点击“撤销”。

“永不过期”不等于永久浏览器登录。客户会话仍受 `PICKUP_SESSION_MINUTES` 限制；会话结束后，客户可以再次使用原取件码登录。

## 5. 交付取件码

租约创建成功后，取件码只显示一次：

1. 立即复制并通过受信渠道交给客户；
2. 不要截图上传到公开平台；
3. 不要把取件码放到 URL 查询参数；
4. 如果遗失，撤销原租约并创建新租约。

数据库同时保存租用码哈希和 Fernet 密文：哈希用于客户登录匹配，密文只在管理员按需查看时解密。租约列表不会直接展示明文。

## 6. 查看与重置租用码

有效租约支持：

- **查看租用码**：按需解密并在弹窗中短时显示，可复制；响应禁止缓存。
- **重置租用码**：生成全新租用码，旧码和全部已登录客户会话立即失效，租约邮箱和期限不变。

从旧版本升级的历史租约没有可恢复密文，会显示只能重置。完成一次重置后即可随时按需查看新租用码。

查看或重置不会把明文写入租约列表、URL、浏览器持久化存储或审计日志。共享屏幕时仍应避免打开租用码弹窗。

## 7. 通过租用码反查邮箱

在租约区域的“租用码查询邮箱”中输入客户提供的完整租用码。系统只计算哈希并精确查询，不解密或扫描全部租约。查询结果包含对应邮箱、租约 ID、状态、到期时间和访问次数，可直接复制邮箱。

租用码不会进入 URL、浏览器历史、查询结果或审计日志；提交后输入框立即清空。有效、已过期和已撤销租约都可以反查，方便售后核对。

## 8. 查看和撤销租约

租约列表显示邮箱、状态、到期时间和访问次数。永久租约显示“永不过期”。

点击“撤销”后：

- 租约立即结束；
- 所有关联客户会话被删除；
- 客户下一次请求立即失败；
- 邮箱可重新分配（前提是仍为可出租且 token 有效）。

## 9. 审计与安全

`rental_events` 会记录创建、兑换、邮件查看、验证码提取、到期和撤销等事件，但不会保存：

- 邮件正文；
- 验证码；
- 取件码明文；
- 邮箱密码；
- Client ID 或 refresh token。

管理员仍可使用原有凭据查看、导入导出和 Microsoft Graph 状态检测功能。生产环境应只通过 HTTPS 和受信反向代理开放服务。
