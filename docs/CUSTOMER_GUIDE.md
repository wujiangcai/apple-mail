# 客户取件指南

## 1. 进入取件页

访问管理员提供的站点地址，并在路径后打开 `/pickup`。例如：

```text
https://mail.example.com/pickup
```

输入管理员提供的取件码。请勿把取件码发送到公开群聊或填写到其他网站。

## 2. 查看邮件

登录后页面只展示当前租约分配的一个邮箱。可以切换：

- 收件箱；
- 垃圾邮件。

切换到任意文件夹后，“提取验证码”会在当前文件夹中查找。新邮件不会通过实时推送自动出现，需要点击“刷新邮件”。

点击邮件可查看正文。HTML 邮件在带 sandbox 和独立内容安全策略的 iframe 中显示，外部脚本和表单无法运行。

## 3. 提取验证码

在“验证码关键词”中可以填写网站名称、发件人或主题关键词，然后点击“提取验证码”。不填写关键词时，系统会在最近邮件中寻找带有验证码上下文的 4–8 位数字或数字字母组合。

验证码只在当前页面内存中显示，不写入浏览器本地存储。

## 4. 理解租约和会话

系统存在两层期限：

- **租约期限**：由管理员设置，可以是指定到期时间或永不过期；
- **当前会话期限**：每次输入取件码后建立的短期登录，会按服务器配置自动结束。

永久租约的页面会显示“租约永不过期”，但当前会话仍会倒计时。会话结束后，返回取件页重新输入原取件码即可继续使用。

指定到期租约在到期后无法重新登录。管理员手动撤销租约后也会立即失效。

## 5. 常见问题

### 提示取件码无效或已过期

可能原因：输入错误、租约到期、管理员已撤销，或者连续错误次数触发了临时限制。确认取件码后稍后再试，仍失败请联系管理员。

### 找不到验证码

请检查垃圾邮件，尝试填写更准确的关键词，并确认目标网站确实已经发送邮件。

### 会话突然失效

可能是当前短期会话到期、管理员撤销租约，或者邮箱的 Microsoft 授权失效。永久租约用户可先重新输入取件码；仍失败请联系管理员。

### 能否查看邮箱密码

不能。客户页面不会返回邮箱密码、Client ID、refresh token、邮箱池或其他客户租约信息。
